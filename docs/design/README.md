# Diseño de pantallas

Referencia visual de las 15 pantallas (390 × 844 px). Las imágenes están en `png/` y los archivos fuente en `src/` (formato del lienzo de diseño; el marcado y los estilos en línea se pueden leer y portar a React). Las imágenes usan tipografías de reemplazo si no cargaron las fuentes; las reales son Fredoka (títulos) y Nunito (texto).
